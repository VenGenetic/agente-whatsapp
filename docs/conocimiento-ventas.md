# Conocimiento de ventas de repuestos

Estado: recopilación guiada con el negocio. Durante esta etapa solo está activo
el agente de recepción; estas reglas no habilitan ventas automáticas.

## Condición de los repuestos

El negocio vende únicamente repuestos **nuevos y originales**. Nunca se debe
decir ni insinuar que son usados, de segunda mano, reciclados, genéricos o
alternativos.

## Principios operativos

- La descripción de un repuesto es evidencia de compatibilidad: todos los
  modelos separados por `/` son compatibles con esa referencia.
- Los modelos de otras marcas que figuran en una descripción son
  compatibilidades directas de su propia marca; no se registran como modelos
  adaptables Daytona.
- Antes de cotizar una carrocería o plásticos se requiere modelo exacto,
  color y la pieza concreta. La pieza lateral del tanque se busca en el
  catálogo como “placa tanque”. El año, posición y otros datos se piden
  cuando cambian la pieza.
- Las piezas que suelen servir a varias motos incluyen maniguetas, timones,
  aros, pastillas, mordazas, cables y estribos sin base. Esto solo orienta la
  búsqueda; la descripción del catálogo es la fuente de compatibilidad.
- No automatizar por ahora piezas de motor. Las atiende una persona.
- Si el cliente envía una foto, el chat se deriva de inmediato a una persona;
  la IA no usa imágenes para identificar pieza o modelo.
- Si el cliente dice que no es la pieza que buscaba, la consulta se complica,
  pide proforma o descuento, debe atender una persona.
- En ventas futuras, la respuesta confirmada debe incluir foto, precio y
  existencia.

## Wing Evo: regla de interpretación

- "Wing Evo" sin más se trata como Wing Evo 200 / Wing Evo 1.
- Los años anteriores a 2024 corresponden al diseño anterior.
- El año 2024 o posterior corresponde al diseño nuevo, Wing Evo 2.
- Si el catálogo nombra explícitamente "Wing Evo 2", algunos repuestos
  compartidos (por ejemplo aros y maniguetas) no requieren año para buscarse.
- Si la descripción nombra un año, ese año identifica el diseño específico.
- La configuración 2024–2025 se mantiene como la misma Wing Evo 2 nueva:
  no se crea una variante adicional. Para plásticos se debe pedir el año,
  pues pueden variar dentro del modelo nuevo.

## Nombres compuestos que no se deben cruzar

- “Evo”, “Evo2” y “Evol” sin otra palabra significan la pasola Evo 2 180.
- “Tekken Evo” y “Wing Evo” son modelos compuestos distintos de la pasola;
  el término “Evo” dentro de esos nombres no crea una compatibilidad con ella.
- “S1ADV” significa S1 Adv 180. Si la descripción dice “Crossover”, es otro
  modelo y no se mezcla con S1 Adv.

## Compatibilidad entre marcas

- Cuando la descripción enumera juntos varios modelos de distintas marcas,
  todos son compatibilidades directas de ese repuesto. Ejemplo: si aparecen
  juntos Wing Evo 2 y Venom Tundra, la referencia se enlaza directamente a
  ambos; no es una adaptación inferida.
- El campo “modelo adaptable” queda reservado para una compatibilidad que el
  equipo confirme manualmente y que no esté declarada en la descripción.
